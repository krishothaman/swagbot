# GOT SWAG BOT

a discord bot where you can make money, talk to ai npcs, and build your own apartment.

basically a little life sim inside discord.

# FEATURES
- make money
- talk to ai npcs
- build and upgrade your apartment
- collect and manage items
- level up and progress

Python 3

SQLite
python-dotenv (loading token from .env)
